בחירת תמונות לאוכל

How to: 1) npm run serve and open http://localhost:8000/photos.html. 2) For each food tap the photo you like, or the emoji to keep the emoji (nothing tapped = emoji). 3) Tap "Download picks.json" (or "Copy"). 4) Run node tools/apply-picks.mjs picks.json, then commit img/foods/*.webp, js/data/photos.js, js/data/photo-credits.js. Picks are saved in this browser as you go.
